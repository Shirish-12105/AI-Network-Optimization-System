# AI Network Optimization System

## Overview
A machine learning project that predicts network latency and provides bandwidth optimization recommendations.

## Features
- Network latency prediction
- Data preprocessing
- Random Forest model
- Performance evaluation

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Model Training
4. Latency Prediction
5. Bandwidth Optimization

## Results
The model predicts network latency using network performance metrics and helps identify suitable bandwidth configurations.
